Open source, built on Zed

Wu is a fork of Zed. It keeps Zed's editor core, GPU rendering and language tooling, and every Zed extension works in Wu.

Questions people ask about Wu

Is Wu free?

Yes. Wu is free and open source under GPL-3.0-or-later, the same license as Zed. There's no paid tier.

Does Wu collect any data?

No. Wu has no telemetry, no crash reporting and no account. It never sends your usage data anywhere.

Does Wu support AI coding agents?

Yes. Wu has built-in support for coding agents like Claude Code, Codex, and OpenCode. However, Wu doesn't support Zed's AI features, like the inline assistant and edit predictions.

Do Zed extensions work in Wu?

Yes. Wu installs extensions from the Zed extension registry, and every Zed extension works.

Can I keep Zed installed too?

Yes. Wu and Zed keep separate settings, in ~/.config/wu and ~/.config/zed. Copy your settings.json and keymap.json over if you want the same setup in both.

Why does macOS say Wu can't be opened?

Wu isn't signed with an Apple Developer certificate yet, so macOS blocks it the first time. The install guide shows the one-time fix.

How is Wu different from Zed?

Wu drops Zed's AI service, collaboration and telemetry features. It has its own agent chat built on the Claude Code, Codex and OpenCode CLIs, its own look, and several other improvements over Zed. See docs for more.

Where can I report a problem?

Open an issue on GitHub. Please check for an existing one first.
