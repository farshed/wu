# Wu

Wu (from [wu wei](https://en.wikipedia.org/wiki/Wu_wei)) is a code editor based off [Zed](https://github.com/zed-industries/zed) that aims to be a native alternative to VSCode.

It removes many of Zed's features in pursuit of simplicity. It aims to be lightweight and cater to the 90% of the users, An area of special focus for Wu is to make it more easily adoptable for VSCode users.

## Features

1. No built-in AI features. You bring your own harness.
2. Wu drops Zed's built-in collaboration, telemetry, dev_container, and Vim features.
3. Lightweight. Wu's idle memory use is ~27% lower than Zed's.
4. Better defaults for smoother transition from VSCode.

Wu is a small code editor built from Zed's core. It has no built-in AI, no collaboration, and no accounts. It's fast, uses little memory, and works with whatever AI tools you already run in your terminal.

Wu is a stripped-down build of Zed for people who keep several projects open at once and use AI tools from the terminal, not from the editor.
