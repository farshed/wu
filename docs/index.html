Edna

A smaller, simpler distribution of the Zed editor.

Edna is built from Zed's source. Everything that is not listed on this page works the way it does in Zed, so the Zed documentation is the reference for settings, key bindings, languages, extensions, tasks, debugging, and remote development.

What Edna is

Edna keeps Zed's editor, terminal, git tools, debugger, language servers, and extensions, and removes the parts that are about AI, collaboration, or Zed's own services. The goal is a fast editor that feels familiar if you come from VS Code, uses less memory, and stays out of your way.

What is removed

  • AI features: the agent panel, inline assistant, edit predictions, and all language model providers.
  • Collaboration: channels, calls, screen sharing, shared projects, and the sign-in flow that went with them.
  • Telemetry, crash reporting, and hang detection. Edna does not phone home.
  • Vim and Helix modes.
  • Dev containers.
  • The REPL, the journal, and the which-key popup.
  • The settings and keymap migrator for old Zed config formats.

If a setting or key binding from the Zed docs belongs to one of these features, it has no effect in Edna.

What is different

  • An activity bar on the side switches between the project, git, outline, search, and debug panels. The debug panel docks on the left by default.
  • The + button in the editor and terminal tab strips sits after the last tab and opens a new file or terminal directly, with no menu.
  • Cmd-W / Ctrl-W never closes a side panel. It only closes editor tabs.
  • Icons and the UI use less memory than Zed for the same workload.

Edna and Zed can be installed side by side. They do not share settings, so copy your settings.json and keymap.json over if you want the same setup in both.

What is the same

  • Extensions come from the Zed extension registry, and every Zed extension works in Edna.
  • Project-level .zed/settings.json, .zed/tasks.json, and .zed/debug.json files work as in Zed.
  • Settings, key bindings, themes, and languages follow the Zed docs.
